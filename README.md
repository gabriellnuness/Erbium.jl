# Erbium.jl
[![CI](https://github.com/gabriellnuness/Erbium.jl/actions/workflows/ci.yml/badge.svg)](https://github.com/gabriellnuness/Erbium.jl/actions/workflows/ci.yml)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.15426587.svg)](https://doi.org/10.5281/zenodo.15426587)


Package to simulate the spectrum of  Erbium-doped superfluorescent fiber sources (SFS).

To install the module:
```Julia
]add https://github.com/gabriellnuness/Erbium.jl
```

### Optical fibers of interest:
Fibercore M3, M5, M12, and Liekki ER30.
